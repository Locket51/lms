# React + Vite
Edemy is a comprehensive Learning Management System (LMS) developed by our team to provide accessible, scalable, and interactive online education.
The platform features a modern UI, course marketplace, video playback system, enrollment tracking, instructor management tools, and a structured course curriculum.
Edemy aims to make high-quality learning available for students of all backgrounds.
